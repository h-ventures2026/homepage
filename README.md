# H Ventures — hventures.co.kr

**Patient capital, walking together.**

A bilingual (English default + Korean toggle) static website for H Ventures, a Seoul-based venture capital firm.

---

## 파일 구조

```
hventures/
├── index.html          영문 메인 페이지
├── ko.html             한국어 버전
├── styles.css          공통 스타일시트 (lang별 분기 포함)
├── app.js              공통 스크립트 (progress bar, reveal, 모바일 메뉴)
├── hunmo_kang.jpeg     강훈모 대표 사진
├── donghyun_jin.jpeg   진동현 대표 사진
├── og-image.png        소셜 미디어 프리뷰 카드 (1200×630)
├── robots.txt          검색엔진 크롤링 가이드
├── sitemap.xml         hreflang 대안 URL 포함 사이트맵
└── README.md           이 문서
```
